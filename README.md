# Task Manager

A small frontend-only task manager built with React and Vite. Tasks are stored in the browser's LocalStorage.

## Features

- Add tasks
- Complete/uncomplete tasks
- Delete tasks
- LocalStorage persistence

## Technologies

- React
- Vite
- JavaScript
- CSS
- LocalStorage

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
